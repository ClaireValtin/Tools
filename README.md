# Tools

A one-click launcher for my medical genetics and lab web tools.

**Open it:** https://clairevaltin.github.io/Tools/

## What it does

Tools is a single home page that lists all my web apps in one place, so you don't have to remember every link:

- Variant interpretation: VariantOne, Atelier ACMG, Nomenclature
- Sanger sequencing: SangerScope, FennecTrace, PrimerScope, GeneDoc
- Clinical genetics: HPO Picker, PedigreeFes, Idiograms
- Disease-focused references: GlobinConsole, Mucoviscidose (CFTR), HCSAtlas, Spectres tumoraux (AtlasOnco)
- Lab calculators and inventories

## How to use

Open the link above. Start typing to filter the list, press **Enter** to open the first match, and click **☆** to pin your favourite tools to the top. Pins are remembered in your browser.
